Automatically removes games from your Steam library using AutoHotkey and PowerShell. Uses screen coordinates and OCR to detect the “Remove from account” option, with customizable click delays and hotkeys.

Controls

F6: Start the macro

F7: Stop and exit

Esc: Exit immediately

Requirements

Windows

AutoHotkey v2

PowerShell

Tesseract OCR

Note: Keep an eye on the macro while it runs. Removing games from your Steam account may be permanent, and some games or licenses may not support removal through the same method.
